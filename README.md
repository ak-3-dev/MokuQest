# MokuQest

## サイト概要
### サイトテーマ

AIによる自動計画とゲーム要素で継続を支援する、目標達成コミュニティサイト
​
### テーマを選んだ理由

私自身、新しいことに挑戦する際に「最初の一歩」は踏み出せるものの、途中で継続できずに挫折してしまう経験が多くありました。
原因は、「最終目標までの道筋が不透明であること」と「日々のタスクが曖昧なまま進めてしまうこと」にあると気づきました。

特に目標が大きくなるほど、タスクの分解やスケジュール設計の難易度が上がり、それがモチベーション低下の大きな要因となります。

そこで、目標と期限を設定するだけでAIが具体的な計画を自動生成し、さらに進捗に応じて柔軟にプランを更新することで、「何をすればいいか分からない状態」を解消できるサービスを考案しました。
「何から手をつければいいか分からない」という不安を取り除き、ゲームのような報酬系（ランクアップ等）を組み合わせることで、努力を「苦行」ではなく「攻略」に変えることを目指しています。
「目標はあるが行動に落とし込めない人」が、迷わず着実に歩みを進められる環境を提供することがこのサービスの目的です。

### ターゲットユーザ

- 「何から始めればいいか」で迷う人
- 一度予定がズレると挫折してしまう人
- 一人の努力に限界を感じている人

### 主な利用シーン

- 新しいスキル習慣のスタート時
- 仕事や家庭で予定が崩れ、モチベーションが下がった時
- 毎日の学習や習慣を「楽しい習慣」に変えたい時
